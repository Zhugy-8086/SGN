## 测试环境

| 项目 | 详情 |
|---|---|
| CPU | AMD EPYC 9Y24（Zen 4），KVM 虚拟化 2 vCPU |
| 系统 | Ubuntu 22.04，g++ 11.4.0 |
| 编译 | `-O3 -std=c++23 -mavx2 -mavxvnni -mavx512f -mavx512bw -mavx512vl -mavx512vnni` |
| 运行时后端 | **`avx512vnni`**（CPUID 自动检测选中） |

## 正确性：238 项全部通过

| 原语 | 项数 | 说明 |
|---|---|---|
| dot16（含 512 位 madd 快速路径） | 18 | bit-exact（含 INT16_MIN 极值） |
| dot8 / dot4（512 位 VNNI） | 28 | bit-exact（含 255×127 满幅） |
| sum_f32 系 | 108 | kRounding 相对容差 1e-4 |
| decode_i16_f32 | 10 | bit-exact（含 0x8000/0xFFFF） |
| reverse / batch_reverse | 64 | bit-exact |
| accum_f32 | 10 | bit-exact |

## 性能基线（K=65536，2 vCPU）

| 原语 | us/call | Mops/s |
|---|---|---|
| dot16（512 位 madd） | 2.835 | 23,121 |
| dot8（512 位 VNNI） | 1.138 | 57,570 |
| dot4 | 1.141 | 57,426 |
| sum_f32 | 3.327 | 19,696 |
| decode_i16_f32 | 10.759 | 6,091 |

> 完整多 K 值（1024/4096/16384/65536）见 `_remote_test_decompressed/sgn_benchmark/result.json`。

## 关键验证

1. **AVX-512 真指令路径 bit-exact** —— 512 位 madd（dot16）+ 512 位 VNNI（dot8/4）在真
   EPYC 上数值正确（本机无 AVX-512 只能逻辑验证，此为其补全）。
2. **AVX512-VNNI CPUID 修复生效** —— 后端名 `avx512vnni` 证明 leaf7 sub0 ECX[11] 检测
   正确（若仍读 sub1 恒 0 会检测不到）。
3. **dot8 > dot16**（57.6 vs 23.1 Mops/s）——512 位 VNNI（64 MAC/指令）密度高于
   512 位 madd（32 元素），符合预期。

## 复现

```bash
# 在 SGN 仓库根目录（含 simd/ 与 sgn_benchmark/）执行
g++ -O3 -std=c++23 -mavx2 -mavxvnni -mavx512f -mavx512bw -mavx512vl -mavx512vnni \
    -I. sgn_benchmark/sgn_benchmark.cpp \
    simd/scalar.cpp simd/simd_dispatch.cpp \
    simd/x86/avx2.cpp simd/x86/avxvnni.cpp simd/x86/ssse3.cpp \
    simd/x86/avx512.cpp simd/x86/avx512vnni.cpp simd/arm/neon.cpp \
    -o sgn_benchmark/sgn_benchmark
./sgn_benchmark/sgn_benchmark        # 人类可读 + result.json
./sgn_benchmark/sgn_benchmark --json-only
```
