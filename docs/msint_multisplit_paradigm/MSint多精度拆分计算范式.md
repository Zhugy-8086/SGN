## 一、核心洞察

### 1.1 现有神经网络的根本局限

现有神经网络（包括所有浮点网络、二值网络、INT8 量化网络）在**数据搬运层面都是 1:1 的**：

```
搬运 1 个 weight → 参与 1 次乘法 → 产出 1 个 partial sum
```

即使矩阵乘法在宏观上是大规模并行、扩散性的，但**微观上每个数据元素的搬运只服务一次计算**。权重矩阵 W 的每个元素 w_ij 只和输入 x_j 做一次乘法。

### 1.2 MSint 的本质区别

MSint 的整数拆分能力使得**一次搬运，多精度解释**成为可能：

```
搬运 1 个 int32 → 可拆分为：
  ├── int16_h（高位）→ 参与粗粒度计算
  ├── int16_l（低位）→ 参与细粒度修正
  ├── int8_hh → 更粗粒度
  ├── int8_hl → ...
  ├── int8_lh → ...
  └── int8_ll → ...
```

一次内存读取，可以产生**多个精度层次的值**，每个都可以独立参与计算。

### 1.3 为什么只有 MSint 能做

| 特性 | 浮点网络 | 二值/INT8 量化 | MSint |
|------|---------|--------------|-------|
| 拆分有数学语义 | ❌ float32→2×float16 无独立意义 | ❌ 只有一个粒度 | ✅ int32→2×int16 严格可逆 |
| 拆分后可独立计算 | ❌ | ❌ | ✅ 各层点积独立 |
| 动态精度选择 | ❌ 全局固定 | ❌ 量化后固定 | ✅ 逐元素可拆分 |
| 一次搬运多精度产出 | ❌ | ❌ | ✅ |

**核心区别**：浮点数的位拆分不是数学操作（IEEE 754 的 sign+exponent+mantissa 不是加法可分解的），但整数的位拆分是严格的 `value = high * 2^p + low`。这是 MSint 独有的数学基础。

## 二、数学基础

### 2.1 多精度拆分点积

一个 N 维点积：

```
y = Σ w_i * x_i
```

如果 w 和 x 都是 int32，拆成 int16 高低位：

```
w_i = w_h_i * 2^16 + w_l_i
x_i = x_h_i * 2^16 + x_l_i

y = Σ (w_h_i * 2^16 + w_l_i) * (x_h_i * 2^16 + x_l_i)
  = (Σ w_h_i * x_h_i) * 2^32 + (Σ (w_h_i * x_l_i + w_l_i * x_h_i)) * 2^16 + (Σ w_l_i * x_l_i)
    └── 粗粒度点积 ──┘     └────── 交叉修正项 ──────┘     └── 细粒度点积 ──┘
```

**一次数据搬运，产出 3 层不同粒度的计算结果**。

### 2.2 累加器溢出分析

多精度拆分点积的三个子点积各自需要独立的累加器，其位宽需求如下：

| 子点积 | 操作数范围 | 单次乘积范围 | K 维累加需求 | 累加器类型 |
|--------|-----------|------------|-------------|-----------|
| 粗粒度 `Σ w_h * x_h` | int16 × int16 | [-2^31, 2^31) | K × 2^31 | **int64**（K > 2 时 int32 溢出） |
| 交叉项 `Σ (w_h*x_l + w_l*x_h)` | int16 × int16 | [-2^31, 2^31) | 2K × 2^31 | **int64** |
| 细粒度 `Σ w_l * x_l` | int16 × int16 | [-2^31, 2^31) | K × 2^31 | **int64** |

**关键约束**：当 K（点积维度）较大时，int32 累加器会溢出。例如 K=1024 时，粗粒度累加和范围可达 1024 × 2^31 ≈ 2^41，超出 int32 范围（[-2^31, 2^31)）。这与 HC16 量化的已知结论一致（参见 `hc16_net.h` 第 122-131 行的分析：K=1024 时 int32 溢出，必须用 int64 累加器）。

**对实现的影响**：
- 拆分后的子点积必须使用 int64 累加器，不能用 int32
- 最终融合结果 `coarse * 2^32 + cross * 2^16 + fine` 需要 96 位以上精度（int128 或大整数）
- 在 SIMD 实现中，int64 累加器的吞吐量为 int32 的一半，需要在性能模型中考虑

**多输出模式的溢出缓解**：如果采用多输出模式（各子点积独立输出，不融合），则每个输出只需要 int64 累加器，不需要 96 位融合。这是多输出模式在实际实现中的一个潜在优势。

### 2.3 两种融合模式

**单融合**（最终合并为一个结果）：

```
y = coarse * 2^32 + cross * 2^16 + fine
```

等价于原始点积，但中间可以利用低位硬件加速。

**多输出**（各层独立输出，后续层分别处理）：

```
y_coarse = Σ w_h * x_h    → 喂给粗粒度路径
y_cross  = Σ w_h * x_l    → 喂给修正路径
y_fine   = Σ w_l * x_l    → 喂给细粒度路径
```

这不是等价于原始点积，而是创造了一种**多尺度表示** — 一次计算产出多个粒度的特征。这是真正的"1对N"。

### 2.4 与 SBE 的类比

SBE（分块矩阵）已经是一个先例 — 它证明了"把一个计算拆成多个子计算再融合"在数学上是成立的。MSint 的拆分是同一类思想在不同维度上的延伸：

```
SBE：  大矩阵 → 空间分块 → 各块独立计算 → 融合
MSint：单个值 → 精度分块 → 各层独立计算 → 融合
```

## 三、MSint "解释性语言"特性

### 3.1 为什么称为"解释性"

MSint 本质上是基于一种协议（类似上下文的解释）：
- 同一个 int32 值在不同上下文下有不同的"解释"方式
- 可以通过数学方式快速拆分（自动拆分）
- 也可以通过人为手动拆分（手动指定精度层次）
- Level 调度的 M-凸性理论（M-convexity，基于 Ibaraki-Katoh 1988）证明贪心算法可以有最优解 → 拆分策略有理论保障

### 3.2 与 Level 调度的关系

Level 调度器可以控制"展开"到哪个精度层次：
- 重要的 token / 神经元 → 展开到细粒度
- 不重要的 → 只用粗粒度
- 这是"解释性"的体现：同一个值在不同上下文下有不同的解释方式

## 四、对 SGN 的潜在影响

### 4.1 前向计算

权重和激活在多精度层次上独立计算，可以跳过低精度层（条件计算）。

### 4.2 反向传播

梯度链路天然多精度，不需要 STE/GEF 等近似 — 因为前向本身就是多精度的，反向也自然多精度。

### 4.3 推理加速

一次内存读取产出多精度特征，在内存带宽受限场景下有天然优势。

### 4.4 为什么前向和反向都可以

多精度拆分是乘法的数学性质，前向（x×w）和反向（grad×w^T）都是乘法，因此两个方向都适用。
