## 3. 各文件职责与依赖

### 3.1 源码（本次新做 3 个）

**gallery_data.py** —— 母本数据源
- 生成两块 int16[1024] 母本：DEMO 渐变图（有结构，视觉惊艳）/ PI 位图（噪声对照）
- 导出为 `.npy` 缓存到 assets/（存在则直接加载，不重复生成）
- 依赖：numpy。被 demo_gallery.py 调用。

**gallery_export.py** —— 第二章后端（磁盘层）
- `export(master, bits, path)`：按位宽视图紧密打包写 .raw（大小 = 母本 × bits/16）
- `load(path, bits, master)`：读回并覆盖写回母本区段（量化语义）
- `projection_consistent(f16_path, f4_path)`：逐位比对公共视图（16bit 导出 view(4)
  == 4bit 导出）→ 返回 True/False + 首个不一致位置
- 依赖：numpy、sgn.MultiScaleView。被 demo_gallery.py 调用。

**demo_gallery.py** —— 唯一主程序（入口）
- 两章 UI：第一章内存层（滑块位宽 + 粒子吞吐 HUD，绿色标）/ 第二章磁盘层
  （导出/柱状图/加载校验，蓝色侧栏）
- 模式切换 Tab 键；`--save gif` 自动走一遍 90-120s 演示流程录片
- 依赖：matplotlib、numpy、gallery_data、gallery_export

### 3.2 既有文件（不动）

- demo_cube.py / demo_eight_worlds.py：概念层 demo，保留在 demo 根，
  路径引用已是 `../demo/...` 相对 build，无需改动。

## 4. 目录职责与生命周期

| 目录 | 职责 | 生命周期 |
|---|---|---|
| demo/ | 概念层 demo + 设计文档 + 本结构 | 常驻 |
| gallery/ | 画廊源码 | 常驻 |
| gallery/assets/ | 母本缓存 | 生成后可复现（删除会自动重建） |
| gallery/exports/ | 演示用的导出存档 | 每次运行按需重建 |
| gallery/output/ | 录制成品（gif/png） | 成品保留 |
| logs/ | 运行日志 | 可清理 |

## 5. 与现有目录的关系（不变更）

- `engine/sgn/build`：编译产物 + 运行目录（`cd build && python ../demo/gallery/demo_gallery.py`）
- `engine/sgn/msint`：MultiScaleView 实现（demo 只读引用，不动）
- `engine/sgn/logs/`：实验日志（与 demo/logs/ 分离，职责不同）
